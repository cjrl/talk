# Chromatic fixed point theory and topology in aviation

Interactive slides for a talk by Christopher J. R. Lloyd.

View them at https://cjrl.github.io/talk/

Plain HTML, CSS and JavaScript. Open `index.html` through any static web server.
Arrow keys move between slides, and the Index button (or the I key) opens a list of all slides.

Third-party libraries are bundled under `vendor/` with their own licenses:
[reveal.js](https://revealjs.com) and [KaTeX](https://katex.org).
